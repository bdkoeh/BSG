# BSG — BSG

## Product
A Codex-first development framework for Bob and other product-minded users. One lead conversation supports high-level discovery, per-slice shaping, parallel delegated delivery, and explicit testing checkpoints.

## First release
One shared skill, ten command entry points, durable project documentation, model/effort guidance, a local record helper, an installer, tests, and a private GitHub repository with README. Claude packaging and a live background runtime are outside v0.1.

## Preferences and authorization
Bob requested building the first version after the discovery conversation, then explicitly requested a private repository on his GitHub account and a README. The initial implementation is authorized. His temporary extra-high thinking preference informed this design work; no universal per-project agent-effort default was agreed. Future BSG projects ask separately about agent effort and human involvement.

Bob works through conversation, not document review. Use adaptive picker questions, product partnership, and research as questions arise. Low involvement can delegate detailed planning. Human checkpoints are selected during planning, with independent continuation explicitly addressed.

## Frontend
BSG v0.1 has no app frontend. For projects built with BSG, discuss vibe upfront and finish the frontend after core behavior.
